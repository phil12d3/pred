# report

Render structured analysis objects into a readable line-based report.

Examples:

- `examples/demo.ns` builds and renders a forecast report.
- `examples/manual_report.ns` shows `create()`, `addSection()`, and `render()`.
- `examples/drift_report.ns` shows `driftReport()`.
- `examples/evaluation_report.ns` shows `evaluationReport()`.
- `examples/table_styles.ns` shows `table()` and `renderTable()` with ASCII, box, and double borders.
- `examples/heatmap_demo.ns` shows `heatmapAscii()`, `heatmapBlocks()`, `heatmapColour()`, and `heatmapLegend()` with resampling and a full colour sweep.
