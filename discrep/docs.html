discrep Documentation

Outlier detection, row comparison, and drift analysis for ns.

Start with examples/demo.ns. It prints one example for each function and shows the shape of the returned objects.

What This Package Is For

discrep is a small analysis package. It does not forecast future values. It helps you answer different questions:

  • Does one stream contain unusually large or unusual values?
  • Are some categorical values rare enough to deserve attention?
  • Do two rows agree, stream by stream?
  • Has a recent window drifted away from a baseline window?

One series means one column of values. A history means a table-like object with streamNames and rows.

How To Import

Use the package wrapper when you want a clean entrypoint:

discrep = import("./discrep.ns");

The wrapper exposes the public functions directly:

  • detectSeries(values, config)
  • profileHistory(history, config)
  • compareRows(expectedRow, actualRow, streamNames, config)
  • detectDrift(baselineHistory, currentHistory, config)

Configuration

Every function that accepts config uses the same shared defaults unless you override them.

Option Default Meaning
minSamples5Minimum number of numeric samples before outlier rules are allowed to flag values.
iqrMultiplier1.5How far beyond the interquartile range a value must be before the IQR rule considers it unusual.
madThreshold3.5Threshold for the modified z-score rule based on median absolute deviation.
rareThreshold0.1For categorical values, anything with a frequency at or below this share is considered rare.
meanShiftThreshold1How much the mean must move before a numeric drift report becomes interesting.
medianShiftThreshold1How much the median must move before a numeric drift report becomes interesting.
ratioShiftThreshold0.1How much the mode share must change before a categorical drift report becomes interesting.
tolerance0.000001Equality tolerance for numeric row comparisons.

In practice, minSamples and the two drift thresholds are the ones you tune most often.

detectSeries

Signature: detectSeries(values, config)

Use this when you want to inspect one list of values. It works with numeric values, categorical values, or a mix. Numeric values are used for outlier calculations. Categorical values are used for mode and rarity information.

What It Returns

count total input size, including missing values.
missingCount how many entries were missing or null.
numericCount how many entries were numbers.
categoricalCount non-missing values that were not numbers.
modeValue the most common value in the whole input list.
modeCount how many times the mode appeared.
modeRatio the mode count divided by the total non-missing count.
min, max, mean, median, q1, q3, iqr, and mad summarize the numeric portion of the series.
outliers is a list of unusual numeric values. Each item has index, value, lowerFence, upperFence, modifiedZ, and reason.
rareValues is used later by history profiling and drift analysis. In the series summary it stays empty unless you are looking at a categorical-only series inside the larger profiling flow.

When A Value Becomes An Outlier

The module uses two numeric checks:

  • IQR fence: values below q1 - iqrMultiplier * iqr or above q3 + iqrMultiplier * iqr.
  • Modified z-score: values whose distance from the median, scaled by MAD, passes madThreshold.

A value can be flagged by either rule. The reason field shows which rule triggered it.

Example

discrep = import("./discrep.ns"); series = discrep.detectSeries([10, 11, 10, 9, 12, 10, 200], {minSamples: 4}); printline(series.mean); printline(series.median); printline(series.outliers[0].value);
Outlier field Meaning
indexThe position of the value in the original input list.
valueThe actual outlier value.
lowerFence / upperFenceThe fence range used by the IQR rule.
modifiedZThe modified z-score computed from the median and MAD.
reasoniqr, mad, or iqr+mad.

profileHistory

Signature: profileHistory(history, config)

Use this when your data is already organized into named streams and rows. The function runs detectSeries for every stream in the history and combines the results into one report.

What It Returns

rowCount total number of rows in the history.
streams a map keyed by stream name. Each value is a series report from detectSeries.
flagged a flat list of all flagged items across all streams.

How To Read It

If you want one stream’s mean or outliers, read report.streams.A.mean or report.streams.A.outliers. If you want everything flagged in one place, use report.flagged.

Example

history = { streamNames: ["A", "B"], rows: [ {A: 10, B: "ok"}, {A: 11, B: "ok"}, {A: 10, B: "ok"}, {A: 9, B: "ok"}, {A: 12, B: "glitch"}, {A: 10, B: "ok"}, {A: 200, B: "ok"} ] }; profile = discrep.profileHistory(history, {minSamples: 4, rareThreshold: 0.2}); printline(profile.rowCount); printline(profile.streams.A.mean); printline(profile.flagged.count());

compareRows

Signature: compareRows(expectedRow, actualRow, streamNames, config)

This function compares two rows stream by stream. It is useful when you want to see whether a forecast matches what actually happened, or when you want to compare two records from different sources.

Inputs

  • expectedRow is the baseline row.
  • actualRow is the row you are checking.
  • streamNames tells the function which fields to compare.
  • config.tolerance controls how close two numeric values need to be to count as matching.

What It Returns

report a list of per-stream comparison items.
matches how many streams matched.
comparisons how many streams were checked.
score matches / comparisons. A value of 1 means every stream matched.

Per-Stream Report Fields

stream the stream name.
expected the baseline value.
actual the value being checked.
matches boolean result for that stream.
delta numeric difference if both values are numbers.
difference the numeric gap, or 0/1 for categorical values.

Example

result = discrep.compareRows( {A: 10, B: "ok"}, {A: 12, B: "ok"}, ["A", "B"], null ); printline(result.comparisons); printline(result.matches); printline(result.score);

Here, B matches and A does not, so the score is 0.5.

detectDrift

Signature: detectDrift(baselineHistory, currentHistory, config)

Use this when you want to compare one time window with another. The baseline is the earlier or normal window. The current history is the newer one. The function profiles both and then compares the per-stream summaries.

What It Returns

streams a list of comparison rows, one per stream.
flagged the subset of streams whose drift looks meaningful according to the thresholds.
baseline the full profile report for the baseline history.
current the full profile report for the current history.

Per-Stream Drift Fields

kind either numeric, categorical, or missing.
meanDelta current mean minus baseline mean for numeric streams.
medianDelta current median minus baseline median for numeric streams.
modeChanged whether the most common value changed.
modeRatioDelta how much the mode share changed.
outlierDelta how many more or fewer numeric outliers the current window has.
rareAdded count of rare values seen in the current profile but not the baseline profile.
rareRemoved count of rare values that disappeared from the baseline profile.
score a simple drift magnitude used for ranking, not a statistical p-value.

How To Read Drift

For numeric streams, large shifts in meanDelta or medianDelta usually mean the center of the distribution moved. A change in outlierDelta means the shape changed as well. For categorical streams, watch modeChanged and modeRatioDelta.

Example

baseline = { streamNames: ["A", "B"], rows: [ {A: 10, B: "ok"}, {A: 11, B: "ok"}, {A: 10, B: "ok"}, {A: 9, B: "glitch"}, {A: 12, B: "ok"} ] }; current = { streamNames: ["A", "B"], rows: [ {A: 20, B: "ok"}, {A: 21, B: "ok"}, {A: 20, B: "warn"}, {A: 19, B: "ok"}, {A: 22, B: "ok"} ] }; drift = discrep.detectDrift(baseline, current, { meanShiftThreshold: 3, medianShiftThreshold: 3, rareThreshold: 0.2, ratioShiftThreshold: 0.1 }); printline(drift.flagged.count()); printline(drift.streams[0].meanDelta); printline(drift.streams[1].modeChanged);

Practical Reading Guide

When To Use Each Function

  • detectSeries: inspect one list of values.
  • profileHistory: inspect every stream in a dataset.
  • compareRows: compare one expected row against one actual row.
  • detectDrift: compare a baseline dataset against a later dataset.

Common Mistakes

  • Passing an ordinary array where a history object is required.
  • Expecting compareRows to understand fields that are not listed in streamNames.
  • Treating score as a statistical confidence value. It is not; it is a simple agreement or drift measure.
  • Using drift thresholds that are too low for noisy data.

Examples

These scripts are in the examples/ folder and are meant to be run directly.

1. Outlier review

Use this when you want to inspect one numeric series and see exactly which value was flagged.

discrep = import("./discrep.ns"); series = [3, 4, 4, 5, 4, 3, 4, 25]; report = discrep.detectSeries(series, {minSamples: 4}); printline(report.mean); printline(report.outliers[0]);

The output tells you the center of the series and gives you the outlier record, including the index and the fence values that triggered it.

Open outlier_review.ns

2. Row comparison

Use this when you already have two rows and want a per-stream check.

expected = {A: 10, B: "ok", C: 3}; actual = {A: 12, B: "ok", C: 3}; result = discrep.compareRows(expected, actual, ["A", "B", "C"], null); printline(result.matches); printline(result.report[0]);

The result object gives you the overall score plus a per-stream report that shows which fields matched, which values differed, and by how much.

Open row_compare.ns

3. Drift review

Use this when you want to compare an earlier baseline against a more recent window.

drift = discrep.detectDrift(baseline, current, { meanShiftThreshold: 2, medianShiftThreshold: 2, rareThreshold: 0.2, ratioShiftThreshold: 0.1 }); printline(drift.flagged.count()); printline(drift.streams[0]);

The drift rows tell you whether the shift is numeric or categorical and which parts changed the most.

Open drift_review.ns
