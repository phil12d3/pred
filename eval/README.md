# eval

Score forecasts, summarize backtests, and compare evaluation runs.

Examples:

- `examples/demo.ns` shows `scoreForecast()` and `summarizeBacktest()`.
- `examples/forecast_score.ns` focuses on one forecast-vs-actual comparison.
- `examples/compare_backtests.ns` shows `compareBacktests()`.
- `examples/drift_score.ns` shows `scoreDrift()`.
- `examples/evaluate_context.ns` shows the current `evaluateSystem()` return shape.
