# simulate

Build deterministic scenario branches by changing the last observed row in a history.

Examples:

- `examples/demo.ns` shows scenario grid creation.
- `examples/apply_changes.ns` focuses on `applyChanges()`.
- `examples/with_last_row.ns` shows `withLastRow()`.
- `examples/scenario_sweep.ns` shows `sweepLast()`.
- `examples/forecast_scenarios.ns` shows `historyFromRows()` and `forecastScenarios()`.
