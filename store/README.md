# store

Keep analysis artifacts together in memory and move them around as plain objects.

Examples:

- `examples/demo.ns` shows basic storage and lookup of analysis artifacts.
- `examples/basic_lookup.ns` focuses on `put()`, `list()`, `has()`, and `lookup()`.
- `examples/drop_and_restore.ns` shows `drop()`, `snapshot()`, and `restore()`.
- `examples/bundle_roundtrip.ns` shows bundle round-tripping.
- `examples/pack_and_bundle.ns` shows `pack()`, `bundle()`, and `unpack()`.
- `examples/save_file.ns` shows `saveFile()` and `loadFile()` for one saved value file.
- `examples/save_store.ns` shows `saveStore()` and `loadStore()` for a whole store snapshot.
