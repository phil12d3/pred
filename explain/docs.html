explain Documentation

Readable summaries for predictions, counterfactual influence, drift, and backtest rows.

Start with examples/demo.ns.

What This Module Is For

explain is a translation layer. Many analysis modules produce detailed objects that are useful for machines and developers but too dense for beginners or reporting code. This module keeps the important evidence and strips away the rest.

The key idea is summarization without inventing new meaning. The functions do not retrain models or recompute metrics. They condense existing outputs into smaller row arrays with consistent field names.

This module is especially useful before passing results into report, because flat rows are easier to render than nested model objects.

Functions

summarizePrediction(predictions)

Use it for: turning per-stream prediction objects into short explanation rows.
Input: an object keyed by stream name, where each entry may contain value and a decision path.
Output: rows with stream, value, and factors.
rows = explain.summarizePrediction({ A: { value: 12, path: [ {feature: "B.current", value: 3, direction: "left", threshold: 4, gain: 0.8}, {feature: "A.lag.1", value: 10, direction: "right", threshold: 8, gain: 0.4} ] } }); // rows[0] = { // stream: "A", // value: 12, // factors: [ // {feature: "B.current", condition: "3 <= 4", gain: 0.8}, // {feature: "A.lag.1", condition: "10 > 8", gain: 0.4} // ] // }

The function keeps at most four path steps. That is a deliberate readability limit. It helps beginners see the strongest rule chain without reading a full tree trace.

summarizeInfluence(influence)

Use it for: flattening counterfactual influence output into one row per source change.
Input: an object with a report array.
Output: rows with source, from, to, strongestTarget, strongestDelta, and effects.
rows = explain.summarizeInfluence({ report: [{ source: "A", from: 10, to: 12, effects: [ {target: "B", delta: 0.2}, {target: "C", delta: 1.5} ] }] }); // rows[0].strongestTarget = "C" // rows[0].strongestDelta = 1.5

The logic here is “find the biggest downstream movement.” It computes the strongest effect by absolute delta, not by signed delta, so large negative and large positive effects are treated as equally strong.

summarizeDrift(driftReport)

Use it for: turning a discrepancy drift report into flat rows that are easier to compare or render.
Input: a drift report with a streams array.
Output: rows with common fields such as stream, kind, score, flagged, plus numeric and categorical drift details where available.
rows = explain.summarizeDrift({ streams: [{ stream: "A", kind: "numeric", score: 0.82, flagged: true, meanDelta: 3.1, medianDelta: 2.7 }] }); // rows[0].meanDelta = 3.1 // rows[0].modeChanged = false // rows[0].rareAdded = 0

This function normalizes mixed drift shapes into a shared row format. Numeric and categorical streams do not naturally carry the same detail fields, so the missing fields are filled with neutral defaults such as 0 or false.

summarizeBacktest(backtestRows)

Use it for: standardizing already-flat backtest rows.
Input: an array of rows like the output of eval.summarizeBacktest().
Output: rows with stream, kind, metric, value, and folds.

This function is intentionally minimal. It keeps a consistent row shape so later rendering code can rely on stable fields.

How To Interpret The Summary Rows

Field Meaning
factors The main decision steps that led to a prediction.
strongestTarget The stream most affected by a source perturbation.
strongestDelta The size of the strongest effect.
flagged Whether a drift summary crossed the discrepancy module’s flag threshold.
metric and value The name of a performance metric and its measured amount.

Example End-To-End Use

predictionRows = explain.summarizePrediction(predictions); influenceRows = explain.summarizeInfluence(influence); driftRows = explain.summarizeDrift(driftReport); backtestRows = explain.summarizeBacktest(metricRows);

The consistent pattern is: take a dense object, produce a row array. That row array is then easier to print, sort, filter, or hand to the reporting layer.
