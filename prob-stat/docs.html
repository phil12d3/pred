1. What prob-stat Is For

prob-stat is a small, explicit statistics toolkit for the ns runtime. It is intended for direct probability calculations, not for large-scale numerical work or machine-learning pipelines. The module is organized around three ideas:

  • Core probability identities and summary statistics
  • Common distributions used in examples and simulations
  • Bayesian updating and a lightweight naive Bayes classifier

The implementation favors simple formulas that can be inspected line by line. That makes it good for teaching, quick analysis, and reproducible examples.

2. Module Layout and Imports

The module is exposed through an umbrella file:

prob = import("./prob-stat.ns"); core = prob.core; dist = prob.distributions; bayes = prob.bayes;

Namespace roles:

coreFundamental probability arithmetic and descriptive statistics.
distributionsBinomial, Poisson, Normal, Uniform, and Geometric distribution helpers.
bayesBayes updates, posterior distributions, and a naive Bayes classifier.
Runtime note: In ns, example files are usually run from the module root, so import paths are relative to that working directory.

3. Core Probability Functions

safeDiv(n, d)

What it does: Divides safely and returns 0 when the denominator is 0.

Use it for: Any probability ratio, rate, or normalization step where you want to avoid a runtime error from a zero denominator. This is especially useful when turning counts into probabilities.

safeDiv(n, d) = { 0, if d = 0 { n / d, otherwise
core.safeDiv(10, 2) // 5 core.safeDiv(5, 0) // 0
// Probability example: count = 3; total = 12; core.safeDiv(count, total); // 0.25

clamp01(v)

What it does: Forces a value into the probability range [0, 1].

Use it for: Cleaning up numeric noise after an approximate calculation so a probability never escapes the valid range.

clamp01(v) = min(1, max(0, v))
core.clamp01(-0.2) // 0 core.clamp01(0.4) // 0.4 core.clamp01(1.8) // 1

ln(x)

What it does: Computes a natural logarithm approximation for positive values.

Math: It reduces x toward [0.5, 1) and then uses a Taylor-series style expansion for ln(1 + u). This is used in entropy and some distribution formulas.

Use it for: scoring models in log-space, computing entropy, or implementing formulas like e^-λ and p^k without a dedicated math library.

ln(x) = ln(m * 2^e) = ln(m) + e * ln(2) with m in [0.5, 1) and a series approximation for ln(1 + u)
// log-space comparison helper: scoreA = core.ln(0.85) + core.ln(0.72); scoreB = core.ln(0.50) + core.ln(0.95);

factorial(n)

What it does: Computes n! for non-negative integers.

Use it for: counting arrangements, permutations, and combinations. It is a building block for binomial and Poisson formulas.

n! = 1 × 2 × 3 × ... × n, with 0! = 1
core.factorial(5) // 120 core.factorial(0) // 1
// 6 choices on a die, 10 independent trials: core.factorial(6); core.factorial(10);

combinations(n, k)

What it does: Computes the binomial coefficient “n choose k”.

Use it for: binomial probabilities, feature subset counting, lottery and hand-selection counts, and any place you need the number of unordered selections.

C(n, k) = n! / (k! (n-k)!)

The implementation uses a multiplicative form to avoid large intermediate factorials:

C(n, k) = Π[i=0..k-1] (n - i) / (i + 1)
core.combinations(5, 2) // 10 core.combinations(52, 5) // 2598960
// Example: number of ways to choose 3 alert checks out of 8 core.combinations(8, 3);

frequencyTable(outcomes)

What it does: Counts how many times each outcome appears in a list.

Use it for: turning raw observations into count data for probability estimates, histograms, and categorical summaries.

count(x) = number of occurrences of x in outcomes total = length(outcomes)
core.frequencyTable(["heads", "tails", "heads"]) // { counts: {heads: 2, tails: 1}, total: 3 }
// Works with numbers too: core.frequencyTable([1, 1, 2, 4, 4, 4]);

probability(outcomes, outcome)

What it does: Returns the empirical probability of a chosen outcome.

Use it for: estimating event frequency from observed data before switching to a theoretical model.

P(x) = count(x) / N
core.probability(["a", "b", "a"], "a") // 2/3
// Use this as the starting point for observed rates: core.probability(["pass", "pass", "fail", "pass"], "pass");

joint(pA, pB)

What it does: Combines two independent probabilities.

Use it for: simple independent event chains, such as "draws with replacement" or "two unrelated checks both passing".

P(A ∩ B) = P(A) × P(B)
core.joint(0.5, 0.5) // 0.25
// Two independent system checks: core.joint(0.98, 0.97);

union(pA, pB)

What it does: Computes the probability that either event happens, using the independence approximation.

Use it for: estimating coverage or at-least-one success scenarios when you can treat the events as independent.

P(A ∪ B) = P(A) + P(B) - P(A)P(B)
core.union(0.3, 0.4) // 0.58
// At least one of two backup links stays up: core.union(0.95, 0.92);

complement(pA)

What it does: Returns the probability that the event does not occur.

Use it for: "none", "not", or "fail" events, such as 1 - success probability or 1 - tail probability.

P(not A) = 1 - P(A)
// P(no error) from an error rate: core.complement(0.02);

conditional(pAandB, pB)

What it does: Computes conditional probability.

Use it for: answer questions like "what is the probability of A given that B has already occurred?"

P(A | B) = P(A ∩ B) / P(B)
core.conditional(0.2, 0.5) // 0.4
// Positive predictive style example: core.conditional(0.04, 0.10);

expectedValue(values, probs)

What it does: Computes the mean of a discrete random variable.

Use it for: pricing, average outcome estimation, expected return, and long-run planning decisions.

E[X] = Σ x_i p_i
core.expectedValue([1,2,3], [0.2,0.3,0.5]) // 2.3
// Expected payout: core.expectedValue([0, 100, 500], [0.7, 0.2, 0.1]);

variance(values, probs, mean)

What it does: Computes the variance of a discrete random variable.

Use it for: measuring spread around the mean. Two distributions can have the same mean but different volatility.

Var(X) = Σ (x_i - μ)^2 p_i
// Compare two payout structures with equal mean but different risk: core.variance([0, 1000], [0.5, 0.5], 500);

stddev(varianceValue)

What it does: Converts variance into standard deviation.

Use it for: putting spread back into the original units of the variable.

σ = sqrt(Var(X))
v = core.variance([1,2,3], [1/3,1/3,1/3], 2) core.stddev(v)

entropy(probs)

What it does: Computes Shannon entropy in bits.

Use it for: measuring uncertainty, comparing peaked vs flat distributions, and summarizing how predictable a categorical system is.

H(P) = -Σ p_i log2(p_i)

Higher entropy means more uncertainty; lower entropy means a more concentrated distribution.

core.entropy([1.0]); core.entropy([0.5, 0.5]); core.entropy([0.9, 0.1]);

normalize(weights)

What it does: Turns non-negative weights into probabilities that sum to 1.

Use it for: converting scores, counts, or model weights into a usable distribution.

p_i = w_i / Σ w_i
core.normalize([2, 3, 5]) // [0.2, 0.3, 0.5]

4. Distribution Functions

Binomial: binomialPMF(n, k, p)

What it does: Probability of exactly k successes in n independent trials with success probability p.

Use it for: defect counts, success counts, yes/no tests, click-through counts, and any fixed-trial Bernoulli process.

P(X = k) = C(n, k) p^k (1 - p)^(n-k)
dist.binomialPMF(10, 3, 0.5) // 0.1171875
// Example: 8 passes out of 10 when p=0.8 dist.binomialPMF(10, 8, 0.8);

Binomial: binomialCDF(n, k, p)

What it does: Probability of at most k successes.

Use it for: threshold questions such as “what is the chance we get 7 or fewer defects?” or “what is the probability of being at or below a target count?”

P(X ≤ k) = Σ[i=0..k] C(n, i) p^i (1 - p)^(n-i)

Binomial: binomialStats(n, p)

What it does: Returns the mean, variance, and standard deviation.

Use it for: quick planning calculations. The mean gives the expected count; the standard deviation shows how much that count typically wiggles.

E[X] = np Var(X) = np(1-p) σ = sqrt(np(1-p))

Poisson: poissonPMF(lambda, k)

What it does: Probability of k events in a fixed interval when events occur independently at average rate λ.

Use it for: call arrivals, failures per hour, rare incidents per mile, or other count data that accumulates over time or space.

P(X = k) = e^-λ λ^k / k!

Poisson: poissonCDF(lambda, k)

What it does: Probability of at most k events.

Use it for: service-level checks like “probability of fewer than 3 incidents” or “probability of at most 2 arrivals in a minute.”

P(X ≤ k) = Σ[i=0..k] e^-λ λ^i / i!

Poisson: poissonStats(lambda)

What it does: Returns mean, variance, and standard deviation for the Poisson distribution.

Use it for: quick approximation of average event count and its natural spread.

E[X] = λ Var(X) = λ σ = sqrt(λ)

Normal: normalPDF(x, mean, sd)

What it does: Probability density of a normal distribution at x.

Use it for: evaluating the height of the curve at a point. This is useful for plotting and comparing density shapes, but not for direct probability of a single point.

f(x) = (1 / (sd * sqrt(2π))) * e^(-(x-mean)^2 / (2 sd^2))

Normal: standardNormalCDF(z)

What it does: Approximates the standard normal cumulative distribution function.

Use it for: converting z-scores into percentiles, critical value checks, and confidence-style calculations.

Φ(z) = P(Z ≤ z), where Z ~ N(0, 1)

Normal: normalCDF(x, mean, sd)

What it does: CDF of a general normal distribution by converting x to a z-score.

Use it for: probability of falling below a threshold, such as below-spec parts, test scores, or measurement limits.

z = (x - mean) / sd P(X ≤ x) = Φ(z)

Normal: normalBetween(lo, hi, mean, sd)

What it does: Probability that X falls within a numeric interval.

Use it for: tolerance windows, pass bands, and “inside the acceptable range” questions.

P(lo ≤ X ≤ hi) = Φ((hi-mean)/sd) - Φ((lo-mean)/sd)

Uniform: uniformPDF(x, a, b)

What it does: Constant density on [a, b].

Use it for: any equally likely continuous range, such as a waiting time between a minimum and maximum bound.

f(x) = 1 / (b - a) for a ≤ x ≤ b, otherwise 0

Uniform: uniformCDF(x, a, b)

What it does: Linear cumulative probability across the interval.

Use it for: answers like “what fraction of the range lies below this cutoff?”

F(x) = 0, x ≤ a F(x) = (x - a) / (b - a), a < x < b F(x) = 1, x ≥ b

Uniform: uniformStats(a, b)

What it does: Returns the mean and variance.

Use it for: summarizing the center and spread of a bounded flat distribution.

E[X] = (a + b) / 2 Var(X) = (b - a)^2 / 12

Geometric: geometricPMF(k, p)

What it does: Probability that the first success happens on trial k.

Use it for: retry processes, first-passage events, and “how many attempts until success?” questions.

P(X = k) = (1 - p)^(k-1) p, for k ≥ 1

Geometric: geometricCDF(k, p)

What it does: Probability that the first success happens by trial k.

Use it for: latency or retry thresholds, like “what is the chance we succeed within 3 tries?”

P(X ≤ k) = 1 - (1 - p)^k

Geometric: geometricStats(p)

What it does: Returns mean, variance, and standard deviation.

Use it for: estimating the long-run expected number of tries needed when each attempt has the same success chance.

E[X] = 1 / p Var(X) = (1 - p) / p^2 σ = sqrt((1 - p) / p^2)

5. Bayes Functions

bayesUpdate(prior, likelihood, evidence)

What it does: Applies Bayes’ theorem for a single hypothesis.

Use it for: medical-test interpretation, spam filtering, diagnostic evidence, and any one-hypothesis posterior update.

P(H | E) = P(E | H) P(H) / P(E)

If evidence is zero, the function returns 0 to avoid division by zero.

// Example: base-rate aware medical test bayes.bayesUpdate(0.001, 0.99, 0.01098);

posteriorDistribution(hypotheses)

What it does: Normalizes a list of hypotheses after weighting each by prior × likelihood.

Use it for: comparing several competing explanations for the same observation, such as models, diseases, or categories.

posterior_i = (prior_i × likelihood_i) / Σ(prior_j × likelihood_j)
bayes.posteriorDistribution([ { name: "A", prior: 0.5, likelihood: 0.8 }, { name: "B", prior: 0.5, likelihood: 0.2 } ]);

train(samples)

What it does: Builds a naive Bayes model from labelled feature samples.

Training rule: Count labels and feature occurrences per label. The model keeps:

  • classCounts[label]
  • featureCounts[label][feature]
  • totalSamples
Interpretation: This is a simple multinomial naive Bayes setup with Laplace smoothing during prediction.
// Example training data for text classification: bayes.train([ { label: "spam", features: ["buy", "cheap"] }, { label: "ham", features: ["hello", "meeting"] } ]);

predict(model, features)

What it does: Returns label probabilities for a feature list under the trained naive Bayes model.

Math: The classifier computes a score proportional to

score(label) ∝ P(label) × Π P(feature_i | label)

In log form this becomes a sum, which is more numerically stable. The implementation then softmax-normalizes the scores back into probabilities.

Use it for: categorizing messages, documents, or small structured feature sets where the independence assumption is acceptable.

model = bayes.train(samples); bayes.predict(model, ["cheap", "buy"]);

sequentialUpdate(initialPrior, steps)

What it does: Repeatedly applies Bayes updates for multiple evidence steps.

posterior_0 = initialPrior posterior_t = bayesUpdate(posterior_{t-1}, likelihood_t, evidence_t)

Use it for: incorporating evidence one piece at a time when a new observation arrives after each update.

bayes.sequentialUpdate(0.2, [ { likelihood: 0.7, evidence: 0.3 }, { likelihood: 0.8, evidence: 0.35 } ]);

7. Practical Usage Patterns

Estimate from observed data

core = prob.core; heads = ["H", "T", "H", "H"]; printline(core.probability(heads, "H"));

Model counts with a distribution

dist = prob.distributions; printline(dist.poissonPMF(2.5, 1)); printline(dist.normalBetween(160, 180, 170, 10));

Turn evidence into a decision

bayes = prob.bayes; posterior = bayes.bayesUpdate(0.001, 0.99, 0.01098); printline(posterior);

Train and predict with naive Bayes

model = bayes.train([ { label: "spam", features: ["buy", "cheap"] }, { label: "ham", features: ["hello", "meeting"] } ]); printline(bayes.predict(model, ["buy"])[0].label);

8. Caveats and Notes

  • Approximation quality: ln, exp, and the normal CDF are implemented with series / approximation formulas, so they are intended for practical educational use rather than high-precision numerical analysis.
  • Discrete vs continuous: Binomial and Poisson use probabilities directly, while Normal and Uniform use density / CDF approximations. A PDF value is not itself a probability; interval probability comes from the CDF or an integral.
  • Naive Bayes independence: predict() assumes features are conditionally independent given the label.
  • Runtime behavior: The ns language is intentionally simple; avoid depending on advanced reflection or external math packages.
  • Numeric extremes: Extremely large values can magnify approximation error, especially in the custom exp and ln helpers.
Best use: start with the examples in the prob-stat/examples folder. They show the exact formulas on real scenarios and are usually the quickest way to understand each function.
