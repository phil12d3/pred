predict Documentation

Multi-stream prediction, explanation, and backtesting for ns.

Start with examples/beginner_guide.ns. It walks through the objects one by one and prints the most important fields in plain language.

What This Package Does

The package learns one small tree-based model per stream. A stream is just one named column in a time-ordered table. The package then predicts the next value for each stream, checks whether the forecast is self-consistent, shows which features mattered, and compares two windows to spot outliers or drift.

If you only want one entrypoint, use predict.ns. It exposes history, features, tree, predictor, explain, backtest, streams, and utils. For outlier detection and drift checks, use the sibling discrep/ package.

Toolkit Map

The prediction package is part of a broader toolkit. Each sibling package has a narrow job so you can combine them without forcing everything into one module.

  • discrep/ handles outlier detection, row comparison, and drift checks.
  • ingest/ converts rows, columns, and raw records into history objects.
  • store/ saves and restores small analysis bundles.
  • eval/ scores forecasts, drift reports, and backtests.
  • simulate/ builds what-if scenarios from existing history.
  • explain/ turns analysis output into beginner-friendly summaries.
  • report/ formats analysis results into readable text reports.

Quick Start

predict = import("./predict.ns"); system = predict.streams.train(["A", "B", "C"], rows, { feature: {lags: 2, rolling: 3, pattern: 2}, tree: {maxDepth: 3, minSamples: 2} }); forecast = predict.streams.forecast(system, rows);

What you get back: system is a trained model bundle. forecast contains the predicted next row, the full per-stream predictions, and a consistency report.

Module Guide

history

create(streamNames) builds an empty history object. It returns { streamNames, rows }.
fromRows(streamNames, rows) copies a list of row objects into a history.
addRow(history, row) returns a new history with one extra row added.
lastRow(history) returns the newest row, or {} if the history is empty.
window(history, maxRows) keeps only the newest rows. This is useful when you want a short recent context.
withCounterfactual(history, streamName, value) copies the history and changes only the last row for one stream.

features

extractAt(history, index, config, categories) builds the feature map used by the tree model.
The returned object has values and categories. values is the feature map. categories stores the numeric codes used for non-numeric values.
Common feature names include A.current, A.lag.1, A.delta.1, A.rolling.3, A.timeSinceChange, and A.pattern.2.
buildTrainingSet(history, targetStream, config) returns { rows, categories }. Each training row has features and the next-step target.

tree

train(trainingRows, config) learns a compact decision tree from feature rows. The returned model has kind and root.
predict(model, features) returns a leaf result with value, path, samples, and depth.
value is the predicted output. path is the list of split decisions. samples is how many training rows reached the leaf. depth tells you how deep that leaf sits in the tree.

predictor

train(history, config) builds one model per stream. The returned system has streamNames, config, models, and categories.
predictOne(system, history, targetStream) returns one forecast object with stream, value, support, samples, depth, path, and features.
support is a simple confidence signal. Higher means the prediction came from a larger leaf.
predictAll(system, history) returns an object keyed by stream name, where each value is the same prediction object returned by predictOne.
predictNextState(system, history) returns { row, predictions, consistency }. row is the full next-state forecast. predictions is the per-stream detail. consistency is the self-check report.
checkForecastConsistency(system, history, forecastRow) returns { report, comparisons, matches, score }. score is the fraction of direct and counterfactual checks that agree.
counterfactualInfluence(system, history, changes) returns { base, report }. base is the normal prediction. report shows how each source change affects every target stream.

explain

summarizePrediction(predictions) turns detailed prediction objects into short rows with stream, value, and factors.
factors is a small list of the strongest tree splits that led to the prediction.
summarizeInfluence(influence) returns rows with source, from, to, strongestTarget, strongestDelta, and effects.

backtest

run(streamNames, allRows, config, minTrainSize, windowSize) does walk-forward backtesting.
The result has folds, stats, and foldCount. Numeric streams report mae. Categorical streams report accuracy.

streams

train wraps the low-level predictor and keeps the stream names with the model.
predict, predictAll, forecast, consistency, influence, and backtestRun are the beginner-friendly entrypoints.
The discrepancy tools live in the sibling discrep documentation. Use them when you want outlier detection, row comparison, or drift analysis alongside predict.

Returned Shapes

Object Main fields What they mean
history streamNames, rows The data you train and forecast from.
features.extractAt values, categories The derived numbers that feed the tree.
predictor.predictOne stream, value, support, samples, depth, path The next value for one stream plus a simple explanation.
predictor.predictNextState row, predictions, consistency A full next-step forecast and its self-check report.
predictor.checkForecastConsistency report, comparisons, matches, score How often the direct forecast agrees with counterfactual checks.
predictor.counterfactualInfluence base, report What changes when one source stream is perturbed.
backtest.run folds, stats, foldCount Walk-forward evaluation across time.
For discrepancy analysis, see the sibling discrep package.

Beginner Example

Run examples/beginner_guide.ns to see all of this in one place.

system = predict.streams.train(["A", "B", "C"], rows, { feature: {lags: 2, rolling: 3, pattern: 2}, tree: {maxDepth: 3, minSamples: 2} }); forecast = predict.streams.forecast(system, rows); printline(forecast.row); printline(forecast.consistency.score);

The first line predicts the next row. The second line tells you how many of the direct and counterfactual checks agreed. A higher score means the forecast is more internally consistent.
